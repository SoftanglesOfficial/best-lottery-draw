## Bundled fonts

The application bundles these variable TrueType fonts for fully offline use:

- Syne — Copyright 2017 The Syne Project Authors
- Plus Jakarta Sans — Copyright 2020 The Plus Jakarta Sans Project Authors
- JetBrains Mono — Copyright 2020 The JetBrains Mono Project Authors

The font files are distributed under the SIL Open Font License 1.1. Their complete
license texts are stored at `public/licenses/LICENSE-*.txt` and packaged by Vite at `licenses/LICENSE-*.txt`.

Sources: the corresponding `ofl/syne`, `ofl/plusjakartasans`, and
`ofl/jetbrainsmono` directories in the
[Google Fonts repository](https://github.com/google/fonts).
